# Salesforce 표준 오브젝트 정리표 (10개)

> 용도: 10/2 09:00 발표 "SFDC Obj 설명" 준비용 학습 자료
> 조회 기준: kai-dev org (`sf sobject describe`로 직접 조회, API 67.0), 2026-10-02
> 주의: **용도 문장은 초안**이다. 발표에서는 본인 말로 바꿔 쓴다. 각 오브젝트는 Object Manager에서 한 번씩 직접 확인하고 체크한다.

발표 순서는 **용도 → 핵심 필드 → 다른 오브젝트와의 관계**.

## 한눈에 보기

| #   | 오브젝트 (Label) | API Name      | ID 앞 3자리 | 한 줄 용도                             |
| --- | ---------------- | ------------- | ----------- | -------------------------------------- |
| 1   | Account          | `Account`     | 001         | 거래처(회사)                           |
| 2   | Contact          | `Contact`     | 003         | 거래처 소속의 사람                     |
| 3   | Lead             | `Lead`        | 00Q         | 아직 거래처로 확정되지 않은 잠재 고객  |
| 4   | Opportunity      | `Opportunity` | 006         | 성사될지 모르는 거래 한 건 (영업 기회) |
| 5   | Case             | `Case`        | 500         | 고객 문의·불만·지원 요청 한 건         |
| 6   | Product          | `Product2`    | 01t         | 판매하는 제품·서비스                   |
| 7   | Price Book       | `Pricebook2`  | 01s         | 제품의 가격표                          |
| 8   | Campaign         | `Campaign`    | 701         | 마케팅 활동(행사, 메일 발송 등)        |
| 9   | Task             | `Task`        | 00T         | 할 일·통화 기록 등 활동                |
| 10  | User             | `User`        | 005         | Salesforce에 로그인하는 사용자         |

> API Name 주의: Product의 API Name은 `Product2`, Price Book은 `Pricebook2`다. Label과 다르다.

## 관계 한눈에 보기

```
Campaign ──────────────┐ (CampaignId)
                       ▼
Lead ──(전환)──▶ Account ◀──(AccountId)── Contact
                  │  ▲                      │
                  │  └──(AccountId)── Case ──┘ (ContactId)
                  ▼ (AccountId)
              Opportunity ──(Pricebook2Id)──▶ Pricebook2
                  │                             │
                  └─ OpportunityLineItem ─ PricebookEntry ─ Product2
Task ─ WhoId ─▶ Contact 또는 Lead
Task ─ WhatId ─▶ Account / Opportunity / Case / Campaign 등
거의 모든 오브젝트 ─ OwnerId ─▶ User
```

화살표는 "관계 필드를 가진 쪽 → 가리키는 쪽"이다.

---

## 1. Account (거래처) — `Account`

- **용도:** 거래 대상 회사·조직. Contact, Opportunity, Case가 여기에 매달린다.
- **핵심 필드**

| API Name            | 화면 Label        | 타입         | 의미                    |
| ------------------- | ----------------- | ------------ | ----------------------- |
| `Name`              | Account Name      | Text         | 거래처 이름 (**필수**)  |
| `Type`              | Account Type      | Picklist     | 고객/파트너 등 유형     |
| `Industry`          | Industry          | Picklist     | 업종                    |
| `AnnualRevenue`     | Annual Revenue    | Currency     | 연 매출                 |
| `NumberOfEmployees` | Employees         | Number       | 직원 수                 |
| `BillingAddress`    | Billing Address   | Address      | 청구 주소               |
| `ParentId`          | Parent Account ID | Hierarchy    | 상위 거래처 (본사-지사) |
| `OwnerId`           | Owner ID          | Lookup(User) | 담당자                  |

- **관계**
  - 가리키는 쪽: `OwnerId`→User, `ParentId`→Account(자기 자신)
  - 가리켜지는 쪽(자식): Contact·Opportunity·Case·Contract·Asset·Order의 `AccountId`

## 2. Contact (연락처) — `Contact`

- **용도:** 거래처에 소속된 사람. 예) 삼성전자의 김부장.
- **핵심 필드**

| API Name               | 화면 Label         | 타입            | 의미          |
| ---------------------- | ------------------ | --------------- | ------------- |
| `LastName`             | Last Name          | Text            | 성 (**필수**) |
| `FirstName`            | First Name         | Text            | 이름          |
| `Email`                | Email              | Email           | 이메일        |
| `Phone`                | Business Phone     | Phone           | 업무 전화     |
| `Title` / `Department` | Title / Department | Text            | 직함 / 부서   |
| `AccountId`            | Account ID         | Lookup(Account) | 소속 거래처   |
| `ReportsToId`          | Reports To ID      | Lookup(Contact) | 상사          |
| `OwnerId`              | Owner ID           | Lookup(User)    | 담당자        |

- **관계**
  - 가리키는 쪽: `AccountId`→Account, `ReportsToId`→Contact(자기 자신), `OwnerId`→User
  - 자식: Case·Opportunity의 `ContactId`, OpportunityContactRole, CampaignMember, Task의 `WhoId`

## 3. Lead (리드) — `Lead`

- **용도:** 아직 거래처·연락처로 확정되지 않은 잠재 고객. 영업이 검증되면 **전환(Convert)** 하여 Account + Contact + Opportunity를 만든다.
- **핵심 필드**

| API Name                                                               | 화면 Label         | 타입     | 의미                        |
| ---------------------------------------------------------------------- | ------------------ | -------- | --------------------------- |
| `LastName`, `Company`                                                  | Last Name, Company | Text     | **필수** 2개                |
| `Status`                                                               | Status             | Picklist | 리드 진행 상태              |
| `LeadSource`                                                           | Lead Source        | Picklist | 유입 경로                   |
| `Rating`                                                               | Rating             | Picklist | 등급 (Hot/Warm/Cold)        |
| `IsConverted`                                                          | Converted          | Checkbox | 전환 여부                   |
| `ConvertedAccountId` / `ConvertedContactId` / `ConvertedOpportunityId` | Converted … ID     | Lookup   | 전환 결과로 만들어진 레코드 |

- **관계**
  - 평소에는 다른 오브젝트와 연결되지 않는다. **전환한 뒤에야** `Converted…Id` 3개가 Account, Contact, Opportunity를 가리킨다.
  - 자식: CampaignMember의 `LeadId`, Task의 `WhoId`

## 4. Opportunity (영업 기회) — `Opportunity`

- **용도:** 성사될지 모르는 거래 한 건. 예) "삼성전자 서버 100대 납품, 5억, 견적 제출 단계".
- **핵심 필드**

| API Name       | 화면 Label      | 타입               | 의미                                              |
| -------------- | --------------- | ------------------ | ------------------------------------------------- |
| `Name`         | Name            | Text               | 기회 이름 (**필수**)                              |
| `StageName`    | Stage           | Picklist           | 영업 단계 (**필수**)                              |
| `CloseDate`    | Close Date      | Date               | 예상 마감일 (**필수**)                            |
| `Amount`       | Amount          | Currency           | 금액                                              |
| `Probability`  | Probability (%) | Percent            | 성사 확률 (단계에 따라 자동)                      |
| `AccountId`    | Account ID      | Lookup(Account)    | 거래처                                            |
| `CampaignId`   | Campaign ID     | Lookup(Campaign)   | 유입 캠페인 (화면 Label: Primary Campaign Source) |
| `Pricebook2Id` | Price Book ID   | Lookup(Price Book) | 사용하는 가격표                                   |
| `ContactId`    | Contact ID      | Lookup(Contact)    | 주 연락처 (API로 조회됨. 화면 목록에 있는지 확인) |

- **관계**
  - 가리키는 쪽: Account, Campaign, Pricebook2, Contact, Owner(User)
  - 자식: **OpportunityLineItem**(이 거래에 포함된 제품), OpportunityContactRole, Task(`WhatId`)
- **확인 포인트:** 화면에서는 `ContractId`(Contract)도 보였다. API 조회 결과에는 없었으니 Object Manager 화면을 기준으로 설명한다.

## 5. Case (케이스) — `Case`

- **용도:** 고객이 제기한 문의·불만·지원 요청 한 건. 서비스(Service Cloud)의 기본 단위.
- **핵심 필드**

| API Name                  | 화면 Label              | 타입        | 의미                          |
| ------------------------- | ----------------------- | ----------- | ----------------------------- |
| `CaseNumber`              | Case Number             | Auto Number | 자동 채번 번호                |
| `Subject`                 | Subject                 | Text        | 제목                          |
| `Status`                  | Status                  | Picklist    | 처리 상태                     |
| `Priority`                | Priority                | Picklist    | 우선순위                      |
| `Origin`                  | Case Origin             | Picklist    | 접수 경로 (전화, 이메일 등)   |
| `Type`                    | Case Type               | Picklist    | 유형                          |
| `AccountId` / `ContactId` | Account ID / Contact ID | Lookup      | 어느 거래처의 누가 요청했는지 |
| `ParentId`                | Parent Case ID          | Hierarchy   | 상위 케이스                   |

- **관계**
  - 가리키는 쪽: Account, Contact, Asset(`AssetId`), Case(`ParentId`, 자기 자신), Owner(User 또는 Queue)
  - 자식: CaseComment(`ParentId`), Task(`WhatId`)
- **확인 포인트:** 필수로 직접 입력할 항목이 없다 (Status, Origin은 기본값이 들어간다).

## 6. Product (제품) — `Product2`

- **용도:** 판매하는 제품·서비스의 목록(카탈로그). 가격은 여기에 없고 **Price Book Entry**에 있다.
- **핵심 필드**

| API Name      | 화면 Label          | 타입      | 의미              |
| ------------- | ------------------- | --------- | ----------------- |
| `Name`        | Product Name        | Text      | 제품명 (**필수**) |
| `ProductCode` | Product Code        | Text      | 제품 코드         |
| `Family`      | Product Family      | Picklist  | 제품군            |
| `Description` | Product Description | Text Area | 설명              |
| `IsActive`    | Active              | Checkbox  | 판매 중 여부      |

- **관계**
  - 자식: **PricebookEntry**(`Product2Id`), Asset(`Product2Id`), Task(`WhatId`)
  - 제품과 가격표는 **PricebookEntry**를 통해 다대다로 이어진다. (제품 1개가 여러 가격표에, 가격표 1개에 여러 제품)

## 7. Price Book (가격표) — `Pricebook2`

- **용도:** 제품별 가격을 모아 둔 가격표. "표준 가격표"가 기본으로 1개 있고, 고객군별 가격표를 추가한다.
- **핵심 필드**

| API Name      | 화면 Label             | 타입     | 의미                   |
| ------------- | ---------------------- | -------- | ---------------------- |
| `Name`        | Price Book Name        | Text     | 가격표 이름 (**필수**) |
| `IsActive`    | Active                 | Checkbox | 사용 여부              |
| `IsStandard`  | Is Standard Price Book | Checkbox | 표준 가격표 여부       |
| `Description` | Description            | Text     | 설명                   |

- **관계**
  - 가리키는 쪽: 없음 (다른 오브젝트를 가리키는 관계 필드가 없다)
  - 자식: **PricebookEntry**(`Pricebook2Id`), Opportunity·Order·Contract의 `Pricebook2Id`

## 8. Campaign (캠페인) — `Campaign`

- **용도:** 마케팅 활동 단위. 누가 참여했고 거기서 어떤 기회가 나왔는지 추적한다.
- **핵심 필드**

| API Name                      | 화면 Label                  | 타입      | 의미                     |
| ----------------------------- | --------------------------- | --------- | ------------------------ |
| `Name`                        | Name                        | Text      | 캠페인 이름 (**필수**)   |
| `Type`                        | Type                        | Picklist  | 유형 (웨비나, 이메일 등) |
| `Status`                      | Status                      | Picklist  | 진행 상태                |
| `StartDate` / `EndDate`       | Start Date / End Date       | Date      | 기간                     |
| `BudgetedCost` / `ActualCost` | Budgeted Cost / Actual Cost | Currency  | 예산 / 실제 비용         |
| `ParentId`                    | Parent Campaign ID          | Hierarchy | 상위 캠페인              |

- **관계**
  - 가리키는 쪽: Campaign(`ParentId`, 자기 자신), Owner(User)
  - 자식: **CampaignMember**(`CampaignId`, 캠페인과 Lead·Contact를 잇는 참여자 목록), Opportunity(`CampaignId`), Task(`WhatId`)

## 9. Task (활동) — `Task`

- **용도:** 해야 할 일, 통화·메일 기록. 어느 사람(Who)에 대해, 어느 건(What)과 관련해 한 일인지를 남긴다.
- **핵심 필드**

| API Name       | 화면 Label     | 타입     | 의미                                                                            |
| -------------- | -------------- | -------- | ------------------------------------------------------------------------------- |
| `Subject`      | Subject        | Combobox | 제목                                                                            |
| `Status`       | Status         | Picklist | 상태                                                                            |
| `Priority`     | Priority       | Picklist | 우선순위                                                                        |
| `ActivityDate` | Due Date Only  | Date     | 기한                                                                            |
| `WhoId`        | Name ID        | Lookup   | **누구와** 관련 (Contact 또는 Lead)                                             |
| `WhatId`       | Related To ID  | Lookup   | **무엇과** 관련 (Account, Opportunity, Case, Campaign 등 여러 오브젝트 중 하나) |
| `OwnerId`      | Assigned To ID | Lookup   | 담당자                                                                          |

- **관계**
  - `WhoId`와 `WhatId`는 **여러 오브젝트 중 하나를 가리킬 수 있는 특별한 필드**(다형성)다. 다른 관계 필드와 다르다.

## 10. User (사용자) — `User`

- **용도:** Salesforce에 로그인하는 사람. 레코드의 담당자(Owner), 만든 사람, 수정한 사람이 모두 User를 가리킨다.
- **핵심 필드**

| API Name                     | 화면 Label              | 타입            | 의미                                                  |
| ---------------------------- | ----------------------- | --------------- | ----------------------------------------------------- |
| `Username`                   | Username                | Text            | 로그인 ID (이메일 형식, 조직 전체에서 유일, **필수**) |
| `LastName`, `Email`, `Alias` | Last Name, Email, Alias | Text            | **필수**                                              |
| `ProfileId`                  | Profile ID              | Lookup(Profile) | 기본 권한 묶음 (**필수**)                             |
| `UserRoleId`                 | Role ID                 | Lookup(Role)    | 역할 (데이터를 어디까지 볼 수 있는지)                 |
| `ManagerId`                  | Manager ID              | Hierarchy       | 상사                                                  |
| `IsActive`                   | Active                  | Checkbox        | 사용 여부                                             |

- **관계**
  - 가리키는 쪽: Profile, UserRole, User(`ManagerId`, 자기 자신)
  - 자식: 사실상 전부. 거의 모든 오브젝트의 `OwnerId`, `CreatedById`, `LastModifiedById`가 User를 가리킨다.
- 과제 ②(Role, Public Group, Sharing, Profile)와 바로 이어지는 오브젝트다.

## 직접 확인 체크리스트 (Object Manager)

각 오브젝트의 **Fields & Relationships**에서 위 API Name과 Data Type이 같은지 본다.

- [ ] Account
- [x] Account 관계 필드 (Owner, Parent, D&B Company) — 확인함
- [x] Contact 관계 필드 (Account, Reports To, Individual) — 확인함
- [x] Opportunity 관계 필드 (Account, Contract, Price Book, Primary Campaign Source) — 확인함
- [ ] Lead / Case / Product / Price Book / Campaign / Task / User

## 발표 때 꼭 말할 것

1. **API Name을 직접 확인했다**: Label과 API Name이 다른 예 — `Account Name`(Contact의 필드)은 `AccountId`, Product는 `Product2`, Price Book은 `Pricebook2`.
2. **`__c`가 없으면 표준**, 있으면 커스텀.
3. **관계 필드 이름은 보통 `~Id`로 끝난다.**
4. **Created By / Last Modified By**는 모든 오브젝트가 공통으로 가진다.
